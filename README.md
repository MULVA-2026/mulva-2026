# MULVA 2026 GitHub Pages website

A responsive static website based on the supplied MULVA workshop proposal.

## Publish
1. Create a GitHub repository such as `mulva-2026`.
2. Upload the *contents* of this folder to the repository root (keep `index.html` at the root).
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, and save.
5. GitHub Pages will publish the project at `https://YOUR-USERNAME.github.io/mulva-2026/`.

For a root URL `https://YOUR-USERNAME.github.io/`, the repository must be named `YOUR-USERNAME.github.io`.

- Confirm workshop acceptance and final date. The supplied proposal says **22 December 2026** and describes the event as proposed.
